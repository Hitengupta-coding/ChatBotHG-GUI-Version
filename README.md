# **ChatBotHG [GUI Version]** 🤖💬  

A simple, interactive chatbot with a user-friendly graphical interface. ✨  

## 🚀 Features  
- **Easy-to-use GUI** for seamless interactions 🎨  
- **Smart responses** based on predefined patterns 🤔  
- **Handles unknown queries gracefully** with a default message 🛠️  

## 🛠️ Installation & Usage  
1️⃣ **Download and extract** the provided files 📂  
2️⃣ **Run the chatbot executable (`ChatBotHG.exe`)** ▶️  
3️⃣ **Start chatting through the GUI** and enjoy! 🗨️💡  

## 📌 Requirements  
- Compatible with **Windows OS** 💻  
- No additional installation needed 🏆  

## 🔍 How It Works  
The chatbot responds based on predefined patterns. If it doesn't recognize an input, it gives a default reply to keep the conversation going. 🎭💬  

## 🗣️ Example Interaction  
💬 **User:** Hello  
🤖 **Bot:** Hi there! How can I assist you?  
💬 **User:** What's the weather like?  
🤖 **Bot:** Sorry, I don't understand.
